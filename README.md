# CS2 Lantern

Windows 原生 CS2 好友开服启动器。优先本机边玩边开，提供工坊地图收藏室、搜索、Steam 链接导入、房间规则和加入命令。基于 C# / .NET 10 / WPF，无浏览器运行时、Web 服务、数据库或第三方 NuGet 依赖。

## v0.5 订阅状态与好友加入

读取当前 Steam 账号 `ugc/730_subscriptions.vdf`，把没有完整地图文件的条目显示为待下载；订阅缓存或文件变化均触发刷新。Steam 尚未同步的新订阅可粘贴多个链接添加。自动补全名称，并显示实际磁盘余量 / 下载失败记录，未下载完整的地图禁止启动。此程序不会伪造 Steam 订阅状态或代替 Steam 下载。

顶部“好友联机”读取真实游戏 `status_json`，生成当前服务器身份的 connect 命令。空身份 `[A:1:0:0]` 会被拒绝。换图或重开后重新读取；可从备用方式选本机 Radmin VPN / ZeroTier 地址。双方必须在同一个组网中，普通家庭内网 IP 不能跨互联网直接连接。程序没有替你创建 VPN 网络、改防火墙或端口映射；尚未进行两台电脑的端到端验证。

## v0.4 地图管理与实用终端

- **删除地图**：选中工坊地图后点击删除，确认实际路径后将该工坊包移入回收站（包括包内其他关卡及分卷）。游戏自带地图不能删除，其他 Steam 库中的副本保留。取消订阅请在 Steam 工坊页操作；仍订阅时 Steam 可能重新下载。
- **自动识别**：默认每 4 秒检查地图文件属性和工坊清单，连续两次稳定后自动扫描；通常下载停止后约 8 秒更新，选择和搜索保留。不读取地图内容来计算指纹。可关闭自动识别；不会自动取消 Steam 订阅，也不会把磁盘上仍存在的文件当作已删除。
- **Steam 工坊**：浏览、导入、选中地图的工坊页均通过 Steam 协议打开。
- **精准补位**：输入记分板中的 T / CT 真人人数，显示目标与各队补位数量。3 对 4 → 4v4，清除旧人机后只给 T 补一个；禁用自动移动真人。执行前从游戏读取真人总数，拒绝大于当前总数的输入。CS2 `status_json` 不提供队伍归属，所以两队人数需要手填，不能声称自动读取。旁观者不填；人员变化后重新执行。
- **持续填充**：保持指定总人数，真人加入时引擎减少人机；另有 T / CT 单独加人机、难度切换。
- **对局控制**：重开、开始 / 结束热身、暂停 / 继续、交换阵营（会重开）。状态显示当前地图、真人和人机总数；日志可导出。

## 游戏终端与地图视图

地图支持“网格 / 列表”切换，默认网格并保存选择；切换视图不改变所选地图。封面按 320 像素解码，避免把原始高清图全部载入显示内存。

点击地图区的“游戏终端”打开独立终端窗口，再点“连接游戏”。新版默认启用外部终端：通过 `-insecure -netconport -netconpassword` 启动本地 CS2，连接只访问本机，随机密码保存在本机数据目录 `console-key.txt`，预览中隐藏密码。本机游戏使用 2121，独立服务器使用 2122。首次启用需要退出旧游戏进程后用新版启动。该模式用于私服；玩官方匹配时退出游戏，从 Steam 正常启动。可取消“外部终端 · 私服模式”开关。

- **平衡人机**：开启队伍平衡，让人机补足指定总人数（玩家 + 人机）。例如房间有 1 名玩家，填 6 则补到 5 名人机。队伍平衡可能在后续回合生效。
- **删除全部人机**：先将 quota 设为 0，再踢出人机，避免自动补回。
- **重开对局**：执行 `mp_restartgame 1`。
- **自定义命令**：输入后回车发送，↑ / ↓ 浏览本次窗口命令历史；支持实时游戏输出与清空显示。

连接会用随机 echo 回显验证确实能与游戏通信；按钮显示已发送不代表引擎允许所有命令，实际结果以终端输出为准。房间管理需要本地房主权限，不能管理你只是玩家的远程服务器。断线后不会自动重放命令。

游戏已运行且终端可连时，“启动所选地图”直接发送换图命令；连接不可用时保留复制命令的回退。终端已连接时，“复制 / 应用规则”直接发给当前终端。关闭启动器或终端不结束游戏。

## 运行

双击 `artifacts/portable/CS2Lantern.exe`（包含运行时的 Windows x64 便携版）。第一次运行会识别 Steam 多库目录。若路径未识别，在“路径 / P2P”选择 `game/bin/win64/cs2.exe`。

### 和好友玩（推荐）

1. 在 Steam 登录并完成 CS2 更新。启动器中点“扫描本地”，选择工坊地图。
2. 在“玩法”选择模式。地图自带脚本玩法用“地图自定义玩法”，默认不覆盖作者规则；需要人机等规则时勾选“覆盖地图默认规则”，设置数量、难度和回合参数。
3. 首次请在游戏内 **Play → Workshop Maps → Open Party** 开启公开队伍。点启动器“启动所选地图”通过 Steam 启动游戏并执行开图配置。游戏已经运行时复制开图命令，在游戏控制台粘贴执行。
4. 好友通过 CS2 好友列表加入。如果快速命令开图未建立可加入的队伍，请使用上面的游戏工坊页选择同一地图并开始，这是 Valve 文档确认的入口。
5. 地图载入后如规则被模式配置或脚本覆盖，点“复制 / 应用规则”，在房主控制台粘贴执行。新回合规则通常从后续回合生效；需要立即重新开局可自行执行 `mp_restartgame 1`。

**控制台是 CS2 的开发者控制台（通常按 `~`），不是 PowerShell / CMD。** 可在游戏设置中开启开发者控制台。

### 获取地图

粘贴 `https://steamcommunity.com/sharedfiles/filedetails/?id=...` 或数字 ID。启动器用 Steam 官方接口验证 CS2 Map 条目、拒绝合集和其他游戏内容，然后打开 Steam 工坊详情页。点击订阅，Steam 下载完成后自动识别（也可手动扫描）。启动器不会代理登录、替用户模拟订阅或另存地图副本。

“补全名称与封面”批量查询名称和标签，最多并发 3 个封面下载，单张限 5 MiB，缓存 7 天。本地名称读取 `publish_data.txt`；离线也能扫描和搜索。扫描仅遍历 Steam 库和显式添加目录，不全盘搜文件。

### IP 独立开服

选择“独立服务器 · IP 直连”，设置端口，可按服务器需求填入自己的 GSLT。启动后在单独服务器窗口查看加载情况，`status` 查询状态，`quit` 停服。房主另开 CS2 后输入：

```text
connect 127.0.0.1:27015
```

局域网好友使用房主实际局域网 IP；公网好友使用可达的公网 IP，并需要相应 UDP 端口转发／防火墙允许，CGNAT 不能靠一个启动参数解决。启动器不自动更改路由器和防火墙。

### Steam P2P 独立开服（实验）

“路径 / P2P”→“备份并启用 P2P 配置”，再选择独立 P2P 模式启动。该路径基于 5Stack 运维文档，保留 Valve 文件的全部现有字段，在 `gameinfo_branchspecific.gi` 的 `ConVars` 添加 `net_p2p_listen_dedicated=1`，在 `NetworkSystem` 设置 `CreateListenSocketP2P=2`。与本机 Open Party 是两条独立路径。

服务器中输入 `status`，将含 `steamid : [A:…]` 的输出粘贴进“连接”页提取本次身份。然后复制加入命令，例如：

```text
connect [A:1:123456789:12345]
```

以上数字仅为格式示例。不能拿个人 Steam ID 替代服务器身份，也不能沿用服务器重启前的匿名身份。本原型采用社区匿名身份流程，P2P 模式不接受 GSLT。服务器网络是否实际可达、SDR 延迟和与当前版本的兼容性仍需双机验证。

P2P 修改有原始字节备份和修改后 SHA-256；恢复前会比对文件，拒绝用旧备份覆盖 Steam 更新或其他修改。启用／恢复时要求 CS2 退出。

## 配置与范围

- 普通数据：`%LOCALAPPDATA%/CS2Lantern`，含偏好、导入条目、元数据、封面、扫描诊断。可用 `LANTERN_DATA_DIR` 改目录。
- 点击启动／应用规则才在游戏 `game/csgo/cfg` 写入带时间戳的 `lantern_*_boot.cfg`、`lantern_*_rules.cfg`，不覆盖 `autoexec.cfg`、`server.cfg` 或 `listenserver.cfg`。
- 房间密码为了引擎读取写入该次 rules.cfg；不存入偏好。GSLT 不写偏好或预览，独立 IP 开服时作为进程参数传递。
- 启动器不接管服务器生命周期；关闭启动器可以节省资源，游戏／独立服务器继续运行。
- 尚未实现：Steam 自动订阅、游戏更新进度、完整服务器就绪探测、远程 RCON 管理、跨机器联机自动验收。
- 地图作者定义的内部关卡、职业或脚本菜单没有统一 API；本版本可设置引擎模式、人机和标准房间规则，不能自动推断每张地图的专用菜单。
- 运行时人数上限还受游戏模式／地图出生点等影响；`-maxplayers` 不是扩大所有地图容量的保证。

## 构建与检查

需要 .NET 10 SDK，可用项目 `tools/dotnet/dotnet.exe`（本次构建所用的本地工具链）或已安装的 SDK。

```powershell
dotnet build src/Lantern.App -c Release
dotnet run --project tests/Lantern.Tests -c Release
dotnet run --project tests/Lantern.Tests -c Release -- --live 'C:\Program Files (x86)\Steam' --network
dotnet publish src/Lantern.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/portable
```

测试不启动游戏、不修改真实游戏配置。`--live` 仅读取实际 Steam 和 VPK；`--network` 读取公开工坊元数据。GUI 的 `--smoke` 扫描后输出自身 WPF 渲染图和基础性能数据并退出，`--smoke-covers` 额外获取前 6 张封面；测试时请指定单独 `LANTERN_DATA_DIR`。

调查依据见 [docs/RESEARCH.md](docs/RESEARCH.md)，本机验收结果见 [docs/VALIDATION.md](docs/VALIDATION.md)。
